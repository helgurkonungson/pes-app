# Публикация: аудитория, возраст, фичеринг

Цель — максимально широкая аудитория и право на редакционные подборки (featuring) в Google Play и App Store. Я не юрист: проверьте раздел о возрасте с юристом перед публикацией.

## Как в приложении устроен возраст (ADR-023)

- Само приложение — учёба по своим материалам и импортированным курсам — работает без AI и без возрастных ограничений.
- Возраст спрашивается **только при подключении сервиса AI**. Это нейтральный экран: год рождения из списка, без подсказки «правильного» ответа. Сохраняется только группа (`child` < 13, `teen` 13–17, `adult` 18+), сам год — нет. Повторно не спрашивается: изменить можно только через «Удалить все данные».
- Минимальный возраст сервиса берётся из его условий (проверено 25.10.2026):
  - Gemini — 18+. Условия Gemini API запрещают приложения, которые ориентированы на младше 18 или, скорее всего, ими используются.
  - Groq — 18+ (Groq Services Agreement, «Age Requirement»). Данные не используются для обучения.
  - OpenRouter — 18+ (Terms, «Eligibility»).
  - Mistral — с 13 лет, до 18 — с разрешения родителей (Consumer Terms, ROW). На бесплатном тарифе Studio данные могут идти на обучение, от этого можно отказаться.
  - Ручной ввод ключа (Claude, ChatGPT, Алиса AI, Qwen, NVIDIA, свой сервер) возрастом не ограничен: владелец ключа уже принял условия своего сервиса.
- Подросток 13–17 видит только Mistral, с галочкой разрешения родителей. Ребёнок до 13 не может подключить AI, но учится без него.

## Google Play

- **Target audience and content**: отметить **13–15, 16–17, 18+**, без групп младше 13. Если включить младше 13, приложение попадёт под Families Policy: все SDK должны быть сертифицированы для семей, действуют жёсткие правила для генеративного AI, а встроенный вход Google и сторонние AI-сервисы становятся проблемой. Программы *Teacher Approved* и *Kids* поэтому недоступны.
- **Рейтинг IARC**: насилия, азартных игр и рекламы нет. В анкете есть вопросы про AI-контент: ответить честно, что AI генерирует учебные тексты по материалам пользователя. Ожидаемый рейтинг — Everyone / Teen. Точный результат даст анкета.
- **AI-контент**: Google требует возможность пожаловаться на сгенерированное прямо в приложении. С 0.13.0 есть «Пожаловаться на урок» (флажок в верхней панели урока и сохранённого урока, ADR-025). Чтобы жалобы приходили разработчику без участия пользователя, задайте переменную GitHub Actions `REPORT_URL` (HTTPS-адрес, принимающий JSON). Без неё жалоба сохраняется на телефоне, а «Отправить разработчику» открывает почту с готовым письмом на support@chompbook.online (пользователь на время уходит в почтовое приложение).
- **Data safety**: материалы пользователя передаются выбранному им AI-сервису с его собственным ключом. Возрастная группа хранится только на устройстве.
- **Что помогает попасть в подборки**: стабильность (без падений и ANR — эмуляторные тесты в CI), поддержка планшетов и альбомной ориентации (есть), светлая и тёмная тема (есть), локализация (9 языков), доступность (axe-проверки в CI), Material-стиль, отзывы и рейтинг, регулярные обновления. Подать заявку на featuring можно через форму Google Play для разработчиков.

## App Store

- **Возрастной рейтинг** (анкета App Store Connect, новые категории 4+/9+/13+/16+/18+). Приложение генерирует контент с помощью AI и открывает страницы сервисов во встроенном браузере (только фиксированные адреса). Ожидаемо **13+**. Не отмечайте «Made for Kids»: это категория для детей, с запретом сторонней аналитики и внешних ссылок без родительского контроля.
- **5.1.2(i)**: явное согласие перед передачей данных стороннему AI уже есть — экраны согласия для каждого сервиса.
- **1.2**: пожаловаться на неуместный контент можно в каждом уроке (флажок), см. ADR-025.
- **4.8**: Sign in with Apple не требуется — вход Google не создаёт аккаунт в приложении.
- **Подборки App Store**: подать историю через форму «Promote your app» в App Store Connect. Важны дизайн, локализация, доступность (VoiceOver), поддержка iPad и Dark Mode.

## Что ещё нужно для широкой аудитории

1. ~~«Пожаловаться на урок»~~ — сделано в 0.13.0; осталось задать `REPORT_URL`.
2. Политика конфиденциальности на своём домене. Нужна и для проверки OAuth в Google.
3. Языки интерфейса: с 0.13.0 их девять (en, ru, uk, be, es, de, fr, zh, hi). Следующие кандидаты — португальский, турецкий, индонезийский. Карточку магазина тоже стоит перевести.
4. Скриншоты и видео для карточки в магазине на нескольких языках и в обеих темах.
