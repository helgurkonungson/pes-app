# learn-01 | 记忆如何运作 | 我们为什么会遗忘
## 记忆的三个阶段
学习任何东西，大脑都要经过三个阶段：先**编码**信息（注意它、理解它），再**存储**，最后**提取**——在需要的时候想起来。

大多数学习困难并不是因为“记性差”，而是编码太弱（一边分心一边读），或者几乎从不练习提取。

## 遗忘曲线
1885 年，德国心理学家赫尔曼·艾宾浩斯背诵了一些无意义的音节，并测量自己随时间推移还记得多少。结果发现，遗忘在最初几个小时和几天里最快，之后逐渐放缓。这就是**遗忘曲线**。

好消息是：每一次成功回忆，都会让遗忘变慢。所以重要的不是你*看*过多少遍，而是你*回忆*过多少遍。

!key 记忆有三个阶段：编码、存储和提取。
!key 我们在最初几个小时和几天里遗忘得最多。
!key 每一次成功回忆都会减缓遗忘。
!key 重要的是回忆了多少次，而不是看了多少次。

?q:e 记忆的哪个阶段是在需要时找回信息？
- 编码
- 存储
+ 提取
- 重读
= 提取就是在需要时把信息从记忆中取出来。

?q:m 艾宾浩斯的遗忘曲线说明了什么？
+ 我们在最初几个小时和几天里遗忘得最快
- 我们每天以同样的速度遗忘
- 一周后我们知道的比刚学完时还多
- 遗忘要一个月后才开始
= 最大的损失发生在刚学完之后，随后曲线趋于平缓。

?q:m 什么最能减缓遗忘？
- 再读一遍课文
+ 成功地回忆学过的内容
- 用荧光笔划重点
- 把笔记放在显眼的地方
= 每一次成功提取都会强化记忆痕迹。

?q:h 有人一边刷信息流一边读完一章，然后抱怨自己“记性差”。哪种解释最准确？
- 他天生记忆力弱
+ 注意力分散导致信息编码不足
- 他在存储阶段把一切都弄丢了
- 这一章太短了
= 没有注意力，信息几乎没有被编码，自然也就没什么可记的。

?r:m 要想长期记住学习内容，应该怎么做？
- 尽可能多读几遍
+ 主动回忆，而不只是看
- 手抄一遍
- 大声朗读
= 回忆是长期记忆的关键。

?r:e 我们学过的内容大多在什么时候遗忘？
+ 最初几个小时和几天里
- 半年之后
- 只在睡觉的时候
- 只要内容清楚就永远不会忘
= 这就是遗忘曲线开头陡峭的部分。

# learn-02 | 记忆如何运作 | 回忆胜过重读
## 测试效应
2006 年，心理学家亨利·罗迪格和杰弗里·卡皮克比较了两组学生。一组把课文读了好几遍，另一组读一遍后尝试回忆内容。一周后，第二组记住的明显更多。这就是**测试效应**，也叫提取练习。

尝试回忆不只是检查自己会不会，它本身就是训练。即使答错了也有帮助：之后正确答案会记得更牢。

## 知道的错觉
重读让人感觉舒服：课文看起来很熟悉，好像已经掌握了。这就是**流畅性错觉**：认出一段文字和独立回忆出来是两回事。

练习提取的简单方法：
- 合上书，用自己的话复述要点；
- 先回答问题，再去重读；
- 制作卡片：正面写问题，背面写答案。

正因如此，Chompbook 的每节课都包含问题和复习。

!key 尝试回忆本身就能强化记忆——这就是测试效应。
!key 重读会制造“知道”的错觉：认出 ≠ 回忆。
!key 回忆出错也有帮助，只要随后看到正确答案。
!key 复述、答题和卡片都是简单的练习方法。

?q:e 什么是测试效应？
- 考试让人紧张，会妨碍学习
+ 尝试回忆学习内容能改善长期记忆
- 只能通过考试来检验知识
- 考试做得越多，需要学的就越少
= 回忆是在训练记忆，而不只是检查记忆。

?q:m 为什么重读常常具有误导性？
+ 熟悉的文字看起来像学会了，其实自己回忆不出来
- 重读伤眼睛
- 重读时总会跳过重点
- 重读完全没有用
= 这就是流畅性错觉：认出比回忆容易。

?q:m 你答错了一道题，然后看到了正确答案。这对记忆意味着什么？
- 这次尝试毫无用处
- 必须立刻把整章重读一遍
+ 这次尝试仍然有帮助：正确答案会记得更牢
- 不确定的时候最好别作答
= 出错后获得反馈同样能强化记忆。

?q:h 哪种备考方式最能利用提取练习？
- 拿着荧光笔把笔记读三遍
- 看着课本用自己的话重写一遍
+ 合上笔记，书面回答问题，然后核对
- 用两倍速看录好的讲座
= 这里你真正从记忆中提取知识，并得到反馈。

?r:m 认出和回忆有什么不同？
+ 认出一段文字比独立复现它容易
- 没有区别
- 回忆比认出容易
- 认出只对学语言有意义
= 流畅性错觉正是来自这个差距。

?r:e 哪种简单方法可以练习提取？
- 在课文下面划线
+ 合上书，复述要点
- 读得更快
- 边听音乐边读
= 不看材料复述就是回忆。

# learn-03 | 记忆如何运作 | 间隔重复
## 间隔效应
如果你间隔一段时间复习，而不是一次性学完，就能记得久得多。这就是**间隔效应**，是学习科学中最可靠的发现之一。

把一小时的学习分成六次、每次 10 分钟、分散在不同的日子，比一个晚上连续学一小时效果更好。考前突击能帮你通过明天的考试，但一个月后几乎什么都不剩。

## 越来越长的间隔
效果最好的是**逐渐拉长的间隔**：第二天复习，然后三天后、一周后、两周后，依此类推。每次复习都稍微“晚”一点：你差点忘了，但还能想起来——正是这份努力强化了记忆。

莱特纳卡片盒就是这个原理：答对的卡片移到复习频率更低的盒子，答错的回到第一个盒子。Chompbook 会自动完成这件事：答错的题第二天再出现，答对的在 3、7、14、30 和 60 天后出现。

!key 间隔复习比连续复习记得更久。
!key 突击对明天有用，长期效果却很差。
!key 最好的是逐渐拉长的间隔：1、3、7、14、30 天。
!key 回忆时稍微费点劲，说明这次复习很有价值。

?q:e 什么是间隔效应？
- 晚上学习效果更好
+ 间隔复习比连续复习带来更持久的记忆
- 课与课之间需要长假
- 每节课必须正好一小时
= 分散练习胜过集中练习。

?q:m 哪种复习安排最有利于长期记忆？
- 一个晚上连续复习五遍
- 每天都一样，永远不变
+ 1 天后，然后 3、7、14 天后
- 只在考前一晚
= 逐渐拉长的间隔既省时间又强化记忆。

?q:m 在莱特纳卡片盒中，答错的卡片会怎样？
+ 回到第一个盒子，出现得更频繁
- 被扔掉
- 移到最后一个盒子
- 不变
= 错误会更频繁地出现，直到掌握为止。

?q:h 为什么在内容已经有点遗忘时复习更值得？
- 总学习时间会更少
+ 回忆时的努力能更有力地强化记忆
- 大脑疲劳时工作得更好
- 因为更容易，答案自己就冒出来了
= 回忆时“合理的困难”会让记忆痕迹更牢固。

?r:e 哪种更好：连续学一小时，还是在不同的日子学六次、每次 10 分钟？
- 连续学一小时
+ 在不同的日子学六次短课
- 一样
- 只取决于一天中的时间
= 这就是分散练习。

?r:m Chompbook 如何安排你答对的题再次出现？
- 再也不出现
- 每天都出现
+ 间隔越来越长：3、7、14、30、60 天
- 只在期末测试中出现
= 答对的题会进入间隔越来越长的复习。

!rubric 写明了主题和目标
!rubric 间隔逐渐拉长

# learn-04 | 深入理解的方法 | 交错练习
## 分块还是交错
我们通常**分块**学习：先做 20 道一种题，再做 20 道另一种。这感觉很高效：每道题都越来越容易。可现实中问题是混在一起出现的，你还得先判断该用哪种方法。

**交错练习**（interleaving）就是把不同类型的题混在一起：A、B、C、A、C、B。在道格·罗勒和凯莉·泰勒 2007 年的数学研究中，练习混合题的学生在最终测试中成绩明显更好，尽管他们觉得练习过程更难。

## 什么时候有效
当主题彼此相似、容易混淆时，交错尤其有用：图表类型、语法时态、公式、画家风格。大脑会学会分辨差异，而不只是重复同一种技巧。

注意：交错的是你已经有所了解的主题。全新的内容先单独学，再混合练习。

!key 分块感觉更高效，但交错在测试中效果更好。
!key 交错训练你选择方法，而不只是套用方法。
!key 对相似、易混淆的主题尤其有用。
!key 新内容先单独学，再混合。

?q:e 什么是交错练习？
- 和朋友轮流学习
+ 把不同类型的题目或主题混在一起练，而不是分块
- 每天换一个学习地点
- 每 5 分钟交替学习和休息
= 交错就是混合练习的类型。

?q:m 为什么分块学习看起来比实际更有效？
+ 同类题越做越容易，让人产生掌握了的感觉
- 分块花的时间更少
- 交错练习什么都记不住
- 分块能同时调动左右脑
= 练习时的顺手不等于测试时的成绩。

?q:m 交错练习对哪类主题特别有用？
- 彼此毫无关联的主题
+ 相似、容易混淆的主题
- 只对体育有用
- 只对最简单的主题有用
= 交错帮助你分辨相似的东西。

?q:h 你开始学三种新题型。怎样安排练习最好？
- 从第一分钟就把三种混在一起
+ 先分别学习每种题型，然后混合练习
- 只把第一种练到完美
- 交错练习，但不核对答案
= 交错适用于你已经部分理解的内容。

?r:m 罗勒和泰勒的研究发现了什么？
- 分块练习的测试成绩更好
+ 混合练习的期末测试成绩更好，尽管练习过程更难
- 没有任何差别
- 学生拒绝做混合练习
= 练习时的困难在测试中得到了回报。

?r:e 除了方法本身，交错练习还训练什么？
+ 选择该用哪种方法
- 不惜一切代价加快解题
- 永远不犯错
- 背答案
= 现实中的问题不会贴着标签出现，需要你自己识别。

# learn-05 | 深入理解的方法 | 解释与联系
## 用自己的话解释
与已有知识联系起来的东西更容易记住。**精细加工**就是问自己“为什么是这样？”以及“这和我已知的有什么关系？”。

**费曼技巧**也类似：用简单的话解释主题，就像讲给初学者听。解释卡住的地方就是知识漏洞——回到资料，弄懂后再解释一遍。

## 文字加图像
另一种方法是**双重编码**：把文字和示意图、表格或图画结合起来。同一个观点的两种形式，为记忆提供了两条通往它的路径。

## 学习风格的迷思
流行观点认为每个人都应按“自己的风格”学习——视觉型看图，听觉型听讲——但这并没有得到研究支持（Pashler 等人 2008 年的综述）。应根据**学习内容**选择形式：流程用图示，规则用例子，技能用练习。

!key 问自己“为什么？”和“这和我已知的有什么关系？”。
!key 费曼技巧：简单地解释，在卡住的地方找到漏洞。
!key 文字配图比单纯文字更容易记住。
!key “按自己的风格学习”缺乏依据：让形式匹配内容。

?q:e 费曼技巧的核心是什么？
- 只读费曼写的书
+ 用简单的话解释主题，找出解释卡住的地方
- 把一切都背下来
- 用两倍速听讲座
= 简单的解释能暴露理解上的漏洞。

?q:m 什么是双重编码？
- 把内容复习两遍
- 同时学两门课
+ 把文字和同一观点的视觉形式结合起来
- 用两种颜色记笔记
= 文字和图像为一个观点提供两条路径。

?q:m 关于“学习风格”（视觉型、听觉型），研究怎么说？
- 按自己的风格学效率翻倍
+ 按风格调整教学没有被证实的好处；更好的是让形式匹配内容
- 学习风格只存在于儿童身上
- 听觉型的人不应该阅读
= Pashler 等人（2008）的综述没有找到支持该假设的证据。

?q:h 阅读复利相关内容时，哪个问题最能触发精细加工？
- 这一章有多少页？
+ 为什么利滚利在长期内影响这么大？
- 这本书是谁写的？
- 教材用的是什么字体？
= “为什么”的问题把新知识和你已经理解的东西联系起来。

?r:m 在费曼技巧中，解释卡住时该怎么做？
+ 回到资料，弄懂后再解释一遍
- 跳过这一段
- 把课本上的句子逐字背下来
- 换一个新主题
= 卡住说明有一个需要填补的漏洞。

?r:e 选择学习形式时应该依据什么？
- 你的“学习风格”
+ 内容本身：流程用图示，规则用例子，技能用练习
- 哪种读起来最快
- 封面的颜色
= 形式应该适合内容。

# learn-06 | 学习习惯 | 注意力与习惯
## 一次只做一件事
在任务之间切换代价很高：每次被打断后，都需要时间重新进入状态。即使手机屏幕朝下放在桌上，也会占用一部分注意力。一个简单的规则：学习时只学一门内容，关闭通知，手机放在另一个房间或开启“勿扰模式”。

## 每天一小份
习惯靠的不是意志力，而是**规律和容易开始**。每天 10 分钟胜过周日学两小时——对记忆（间隔效应！）和对习惯都是如此。

**“如果……就……”**计划（执行意图）很有帮助：“如果早上在地铁里坐下，我就打开一节课。”彼得·戈尔维策的研究表明，这样具体的计划能提高你真正兑现承诺的可能性。

## 别让链条断掉
连续学习的天数会激励人：你不想中断它。但错过一天不是失败。关键是不要连续错过两天。Chompbook 里的冻结和休息日正是为此而设。

!key 任务切换消耗注意力：学习时关掉通知。
!key 每天短时间学习胜过偶尔长时间学习。
!key “如果……就……”计划把学习和具体情境联系起来。

# learn-07 | 学习习惯 | 睡眠、运动与休息
## 睡眠巩固记忆
睡眠时，大脑会处理并巩固白天学到的东西——这叫**记忆巩固**。睡眠不足对学习有双重伤害：今天注意力变差，明天的内容也巩固得更差。考试前一晚，睡觉比熬夜突击更好。

## 休息与运动
注意力无法无限持续。短暂休息有助于保持专注。一种流行的形式是**番茄工作法**：工作 25 分钟，休息 5 分钟。这不是自然法则，只是一个方便的框架——找到适合自己的节奏。

休息时，最好起身活动，而不是刷信息流：散散步或做几个拉伸能让注意力得到休息，而社交媒体会再次占用它。规律的体育活动总体上对大脑和情绪都有好处。

!key 睡眠时，大脑会巩固白天学到的内容。
!key 睡眠不足既损害注意力，也损害记忆。
!key 短暂休息有助于保持专注；番茄工作法是方便的框架，不是法则。
!key 休息时多活动，少刷屏。

# learn-08 | 学习习惯 | 你的学习计划
## 可检验的目标
“学英语”不是目标，而是梦想。好的学习目标是**具体且可检验的**：“三个月后，我能用英语进行一次 15 分钟的工作通话。”这样你就知道该练什么，也知道怎样算达成。

把大目标拆成一次学习就能完成的小步骤。每一步都应以行动结束：回答问题、完成练习、在工作中应用。

## 资料与检验
选择 1–3 个好的资料，不要在十几门课之间来回跳。在 Chompbook 中，你可以创建自己的技能，并添加书籍、文章和链接——应用会把它们拆分成带问题的每日小份。

定期检验自己：阶段测试和期末测试能显示哪些已经掌握、哪些需要复习。每周问自己一次：什么有效，什么碍事，要改变什么？

## 总结
回忆胜过重读，按逐渐拉长的间隔复习，交错练习相似的主题，用自己的话解释，每天学一点，睡个好觉——这就是有科学依据的学习。

!key 把大目标拆成一次学习就能完成的步骤。
!key 1–3 个好资料胜过同时上十几门课。
!key 每周一次：什么有效，什么碍事，要改变什么？
