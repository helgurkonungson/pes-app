# money-01 | 基础 | 预算：钱去哪儿了
## 先记录
预算不是从限制开始，而是从**了解**开始：进来多少钱，花到了哪里。用一两个月记录所有支出——在银行 App、电子表格或笔记本里都行。很多人会对“小额”支出感到吃惊：咖啡、外卖和各种订阅加起来是一笔不小的数目。

把支出分成**必需**（住房、水电燃气、食物、交通、还款）和**想要**（餐厅、娱乐、犒劳自己）会很方便。

## 50/30/20 参考比例
一个流行的方案来自伊丽莎白·沃伦和阿梅莉亚·沃伦·泰亚吉的书《All Your Worth》（2005）：税后收入的约 **50%** 用于必需，**30%** 用于想要，**20%** 用于储蓄和提前还债。

这是参考，不是法则：房租高的话，比例就会不同。关键是让储蓄成为预算中固定的一项，而不是“剩下多少算多少”。

## 先支付给自己
**在发工资当天**就把一部分收入存起来——用自动转账。这样储蓄就不取决于月底的意志力。

!key 预算从记录开始：进来多少，花到哪里。
!key 支出分为必需和想要。
!key 50/30/20 是参考：必需、想要、储蓄。
!key 发工资当天自动储蓄。

?q:e 做预算从哪里开始？
- 放弃一切娱乐
+ 记录收入和支出
- 买股票
- 办一张信用卡
= 首先要弄清钱去了哪里。

?q:m 50/30/20 方案是什么意思？
- 50% 娱乐，30% 吃饭，20% 交税
+ 约 50% 用于必需，30% 用于想要，20% 用于储蓄和还债
- 50% 储蓄，30% 还债，20% 住房
- 每天花 50 元
= 这是分配税后收入的参考。

?q:m “先支付给自己”是什么意思？
+ 在发工资当天就把一部分收入存起来
- 先给自己买礼物
- 不付账单
- 全部花掉，年底再存
= 自动转账让储蓄变得规律。

- 放弃这个方案，什么也不存
+ 继续定期储蓄，压缩“想要”的部分——比例可以调整

- 餐厅和电影
- 新的电子产品
- 旅行

# money-02 | 基础 | 应急储备金
## 为什么需要
**应急储备金**是用来应对意外的钱：失业、生病、紧急维修。没有它，任何麻烦都会变成高息债务。

常见的参考是 **3–6 个月的必需支出**。收入不稳定的人（自由职业者、季节性工作）或需要抚养家人的人，应该瞄准上限甚至更多。

## 放在哪里
应急储备金应该：
- **随时可取**——一两天内能取出，没有损失；
- **安全**——没有损失本金的风险；
- 与日常消费卡**分开**，免得不小心花掉。

通常是储蓄账户或可以随时支取的存款。股票和加密货币不合适：需要用钱的时候，它们可能正在下跌。

## 从哪里开始
如果 3 个月看起来遥不可及，就先定一个小目标——比如一个月的支出——然后定期存钱。先建立应急储备金，再开始投资。

!key 应急储备金是应对意外的储备，避免陷入债务。
!key 参考标准是 3–6 个月的必需支出。
!key 保持随时可取、安全，并与日常消费卡分开。
!key 先建应急储备金，再投资。

?q:e 应急储备金是做什么用的？
- 买新手机
+ 不借债地度过意外事件
- 投资股票
- 支付假期旅行
= 它是应对麻烦的财务保险。

?q:m 最常推荐的应急储备金规模是多少？
- 一辈子一个月的工资
+ 3–6 个月的必需支出
- 一个月工资的 10%
- 五年的收入
= 收入不稳定时，要瞄准上限。

?q:m 为什么股票不适合做应急储备金？
- 普通人买不了股票
+ 需要用钱时它们可能正在下跌，你只能亏本卖出
- 它们总是涨得太慢
- 股票卖不掉
= 应急储备金需要的是安全，而不是收益。

?q:h 一位有孩子、收入不稳定的自由职业者正在建立应急储备金。哪种做法更合理？
- 最少一个月，其余全部投入加密货币
+ 目标定在 6 个月支出或以上，存放在可随时支取的独立账户
- 不存储备金，办张信用卡就行
- 把储备金放在日常消费账户里
= 不确定性越高，储备就要越多。

?r:m 应急储备金应具备哪些特点？
+ 随时可取、安全、与日常开销分开
- 高收益、高风险
- 长期锁定
- 全部买一家公司的股票
= 困难时刻它必须触手可及。

?r:e 先建应急储备金还是先建投资组合？
+ 应急储备金
- 投资组合
- 同时进行，只买股票
- 都不需要
= 没有储备金，任何麻烦都可能迫使你亏本卖出投资。

# money-03 | 债务 | 贷款与债务
## 全部成本
贷款是一种现在购买、以后多付钱的方式。比较贷款时，不要看广告上的利率，而要看**贷款总成本**——包含所有强制费用的年化利率：保险、手续费、服务费。不同国家叫法不同：年化百分率（APR）、实际年利率等。

## 信用卡
很多信用卡有**免息期**：如果在免息期结束前全额还清账单，就不收利息。但如果只还最低还款额，债务减少得非常慢，而信用卡利率通常很高。用信用卡取现往往不享受免息期，费用也更高。

## 偿还多笔债务
- **雪崩法**：先还利率最高的债务——总共付的利息更少。
- **雪球法**：先还金额最小的债务——快速取得的胜利能保持动力。

无论哪种方法，其他债务都要按时支付最低还款额，一次也不要逾期。借新债还旧债，只有在新贷款的总成本确实更低时才有意义。

!key 按总成本而不是广告利率比较贷款。
!key 按时全额还清账单，免息期才有效。
!key 只还最低还款额会拉长债务、增加成本。
!key 雪崩法省钱，雪球法保持动力。

?q:e 选择贷款时应该比较什么？
- 横幅广告上的利率
+ 包含所有强制费用的贷款总成本
- 卡片的颜色
- 银行网点的数量
= 手续费和保险会大大增加成本。

?q:m 如果信用卡只还最低还款额，会发生什么？
- 一个月就能还清
+ 债务减少得非常慢，利息却在不断累积
- 银行会免除剩余部分
- 不收任何利息
= 最低还款额主要用来支付利息。

?q:m 什么是“雪崩法”？
+ 先还利率最高的债务
- 先还金额最小的债务
- 借新贷款还旧贷款
- 所有债务平均偿还
= 这样能把支付的总利息降到最低。

?q:h 银行建议把两笔贷款合并成一笔。什么时候这样做有意义？
- 总是有意义，因为只还一笔更方便
+ 当新贷款的总成本（含所有费用）低于原来的贷款时
- 当新贷款期限更长时，不管利率如何
- 永远没有意义
= 方便不应该让你多花钱。

?r:m 信用卡的免息期什么时候才能真正让你免付利息？
+ 在免息期结束前全额还清账单时
- 支付了最低还款额时
- 任何交易都总是免息
- 取现时
= 只还一部分通常就会失去免息期。

?r:e “雪球法”的好处是什么？
- 在任何情况下成本都最低
+ 快速取得的胜利能保持动力
- 完全不用还款
- 债务会自动消失
= 还清一笔小债能给你继续前进的动力。

!open 描述你会如何规划偿还三笔债务：信用卡、个人贷款和欠朋友的钱。你会选择哪种方法？为什么？

!rubric 考虑了利率或期限
!rubric 计划中没有新的逾期
!model 我会选雪崩法：先还信用卡，因为它的利率最高——每月尽量多还一些，超过最低还款额。个人贷款按计划还，不逾期。朋友的借款没有利息；我会和他商量每月还一小笔，最后还清。

# money-04 | 让钱增值 | 复利
## 利滚利
**复利**是指收益不仅来自本金，也来自已经获得的利息。例子：10,000 按年利率 10% 复利计算。一年后——11,000，两年后——12,100，10 年后——约 **25,900**。如果不复利，只有 20,000。

## 时间是你最大的盟友
越早开始，效果越强：后面几年的收益比前面几年更多。从年轻时开始定期存一小笔钱，可能超过很晚才开始的大笔投资。

**72 法则**可以估算钱翻倍需要多少年：用 72 除以年利率（百分数）。8% 时约 9 年，12% 时约 6 年。

## 它是双向的
复利也会对你不利：未还清的高息债务会以同样的速度增长。所以在开始投资之前，先还清高成本债务是明智的。

!key 复利是收益再生收益：增长会随时间加速。
!key 尽早开始比投入大笔金额更重要。
!key 72 法则：翻倍时间 ≈ 72 / 利率。
!key 面对高息债务，复利同样卖力——只是对你不利。

?q:e 什么是复利？
- 很难计算的利息
+ 本金和已获得的利息都产生收益
- 只有银行才付的利息
- 存款税
= 加速增长正是来源于此。

?q:m 按照 72 法则，年利率 6% 时钱翻倍需要多少年？
- 6 年
+ 约 12 年
- 72 年
- 3 年
= 72 / 6 = 12。

?q:m 为什么尽早开始如此重要？
+ 复利有更多时间发挥作用，而最后几年的增长最大
- 年轻人能拿到更高的利率
- 晚了就不允许存钱了
- 早开始并不重要
= 时间对效果的放大作用超过投入的多少。

?q:h 一个人有一张高息信用卡欠款，想开始投资。先做什么更明智？
- 去投资，债务先放着
+ 还清高成本债务：它以同样的复利增长，只不过是对你不利
- 再借一笔钱去投资
- 不再还信用卡
= 确定能省下的利息通常胜过预期的收益。

?r:m 10,000 按年利率 10% 复利，2 年后变成多少？
- 12,000
+ 12,100
- 11,000
- 20,000
= 10,000 × 1.1 × 1.1 = 12,100。

?r:e 72 法则是做什么用的？
+ 估算一笔钱需要多少年翻倍
- 计算税款
- 选择银行
- 了解汇率
= 72 除以利率，得到大致的翻倍时间。

!open 向弟弟或妹妹解释，为什么现在就值得开始存小钱。用一个复利的例子。
!rubric 解释了复利
!rubric 有数字例子
!rubric 强调了时间的作用
!model 假设你存下 1,000，每年有 10% 的收益。第一年是 +100，第二年已经是 +110，因为去年的收益也在产生利息。10 年后你会有将近 2,600——一分钱都没有再往里加。越早开始，这个雪球滚得越久。

# money-05 | 让钱增值 | 通货膨胀与实际收益
## 钱会贬值
**通货膨胀**是物价随时间上涨。如果一年内物价上涨了 8%，同样的钱能买的东西就少了。“压在床垫下”的钱会失去购买力。

## 实际收益
重要的不是承诺给你的百分比，而是**扣除通胀后**剩下多少。粗略地说：实际收益 ≈ 名义利率 − 通胀率。存款利率 6%、通胀 8%，实际收益约为 **−2%**：账户里的钱变多了，但能买的东西变少了。

如果你所在的国家对收益征税，也要考虑进去——它同样会降低实际收益。

## 由此可见
- 拿收益和通胀比，而不是和零比。
- 长期目标（养老、子女教育）需要平均能跑赢通胀的投资——但它们伴随着风险（下一课）。
- 应急储备金是例外：对它来说，安全比跑赢通胀更重要。

!key 通货膨胀是物价上涨，钱随时间能买的东西变少。
!key 实际收益 ≈ 利率 − 通胀率。
!key 收益税同样会降低实际收益。
!key 长期目标需要能跑赢通胀的投资。

?q:e 什么是通货膨胀？
- 物价下降
+ 物价随时间上涨，钱能买的东西变少
- 购物税
- 涨工资
= 同样的钱一年后能买到的商品更少。

?q:m 存款年利率 5%，通胀率 7%。实际收益大约是多少？
+ 约 −2%
- 约 +12%
- 约 +2%
- 正好 5%
= 5 − 7 = −2：钱变多了，购买力却下降了。

?q:m 投资收益应该和什么比较？
- 和零比
+ 和通胀比
- 和某种热门加密货币的价格比
- 和邻居的收益比
= 关键在于投资能否跑赢物价上涨。

?q:h 为什么应急储备金不需要为了跑赢通胀而去投资？
- 因为通胀不存在
+ 对它来说安全和随时可取更重要；追求收益会增加风险
- 因为储备金不能存在银行
- 因为储备金必须以现金形式放在家里
= 储备金有不同的任务——随时可用且没有损失。

?r:m 通胀期间“压在床垫下”的现金会怎样？
- 升值
+ 失去购买力
- 什么也不会发生
- 变成外币
= 面值不变，但能买的东西变少了。

?r:e 怎样粗略估算实际收益？
+ 利率减通胀率
- 利率加通胀率
- 利率乘通胀率
- 通胀率减税
= 不用精确公式的快速估算。

# money-06 | 让钱增值 | 风险与分散投资
## 收益与风险相伴
预期收益越高，风险就越高——价值波动以及损失部分本金的可能性。不存在同时**高收益、安全且随时可取**的投资。如果有人向你“保证”这一切，那就是危险信号。

## 不要把鸡蛋放在一个篮子里
**分散投资**是把钱分配到不同的资产上：不同的公司、行业、国家、投资类型。一项投资下跌时，其他投资能缓冲冲击。获得广泛分散的简单方法是**指数基金**，它一次买入许多公司。

## 投资期限与耐心
- 一两年内要用的钱，不应该投入高风险资产。
- 对于 10 年以上的目标，波动更容易熬过去——有时间恢复。
- 最大的错误是在下跌时恐慌抛售，在高点时狂热买入。
- 只投资你理解的东西，并留意费用：它们会侵蚀收益。

!key 高收益总是伴随着高风险。
!key “高收益、安全、有保证”的承诺是危险信号。
!key 分散投资能限制单项投资失败带来的损失。
!key 投资期限决定可以承受的风险。

?q:e 什么是分散投资？
- 把所有钱投入一家有前景的公司
+ 把钱分配到不同的资产上以降低风险
- 频繁买卖股票
- 只持有现金
= 不要把鸡蛋放在一个篮子里。

?q:m 有人承诺每月 5% 的收益，“有保证、无风险”。该怎么看待？
- 赶紧全部投进去
+ 这是危险信号：没有风险的高收益并不存在
- 对新手来说是正常的产品
- 投一半
= 这样的承诺是诈骗的常见迹象。

# money-07 | 防范 | 诈骗与庞氏骗局
## 骗子怎样行骗
几乎所有骗局都在利用情绪：**恐惧**（“你卡里的钱正在被盗”）、**贪婪**（“每月 30% 收益”）或**紧迫感**（“一小时内决定”）。目的是让你不假思索地快速行动。

常见手法：
- 自称“银行安全部门”或“警察”打来电话，要求你把钱转到“安全账户”；
- 要求你告诉他们**短信验证码**、卡片安全码（CVV）或密码；
- “朋友”发消息要你紧急借钱——其实账号被盗了；
- 网址相似的假冒商店和银行网站。

## 庞氏骗局
庞氏骗局用新成员的钱向老成员支付“收益”。迹象：保证高收益、没有清晰的盈利来源、拉人头有奖励、催促“现在就加入”。新钱迟早会断流，大多数参与者会血本无归。

## 防范规则
- 银行从不索要短信验证码，也从不把钱转到“安全账户”。
- 挂断电话，拨打银行卡背面的号码回拨银行。
- 通过电话核实“朋友”的请求。
- 不要着急：紧迫感是骗子的主要工具。

!key 骗子利用恐惧、贪婪和紧迫感。
!key 永远不要透露短信验证码、CVV 或密码——即使对方自称“银行”。
!key 庞氏骗局用新成员的钱支付老成员。
!key 挂断电话，拨打官方号码回拨银行。

?q:e 有人自称“银行”打来电话，要你提供短信验证码来取消一笔交易。你怎么做？
- 告诉他验证码，毕竟是银行打来的
+ 挂断电话，拨打银行卡上的号码联系银行

- 让他晚点再打来，到时候再告诉他
= 真正的银行不会索要验证码。

?q:m 哪个迹象是庞氏骗局的典型特征？
- 详细的报告和清晰的业务
+ 保证高收益，拉人头有奖励
- 收益低但稳定
- 随时可以无条件取出资金
= 庞氏骗局需要新钱来支付老成员。

?q:m 朋友发消息：“急用，借我 500，回头解释。”你怎么做？
- 马上转账——是朋友嘛
+ 打电话给朋友，听到本人声音再确认
- 转一半

= 账号会被盗；要通过其他渠道核实。

?q:h 为什么骗子几乎总是制造紧迫感？

- 因为银行每天只营业一小时

- 为了帮你节省时间

?r:m 接到可疑的“银行”来电，应该拨打哪个号码核实？

= 只能是你自己拨打的官方号码。

- 无聊和疲惫
+ 恐惧、贪婪和紧迫感

# money-08 | 防范 | 财务目标与计划
## 有数字、有日期的目标
“多存点钱”不是目标。好的财务目标是**具体的**：金额、期限和用途。“2 年后攒够 20,000 付首付”就变成了一个清晰的每月存款额——约每月 833，不计利息。

## 步骤顺序
一个适合大多数人的典型顺序：
1. 记录支出，制定预算。
2. 所有债务按时支付最低还款额，不逾期。
3. 初步的应急储备金——至少一个月的支出。
4. 还清高成本债务。
5. 完整的应急储备金——3–6 个月。
6. 长期目标和分散投资。

## 自动化与复盘
- 设置在发工资当天自动转账到各个目标。
- 每隔几个月复盘一次预算和目标：生活在变化。
- 做重大决定（房贷、投资、保险）前，研究条款，必要时咨询不靠卖产品拿佣金的专业人士。

!key 目标 = 金额、期限和用途。
!key 用目标金额除以月数，得出每月定期存款额。
!key 顺序：预算 → 不逾期 → 应急储备金 → 高成本债务 → 投资。
!key 自动存款，每隔几个月复盘计划。

+ 不靠卖产品拿佣金的专业人士
- 随便一个承诺高收益的博主
- 不用咨询——一分钟就决定

- 没必要，而且有害
= 发工资当天自动转账是最可靠的方式。

+ 复盘一下：生活和收入都在变化
