# data-01 | 数据如何组织 | 什么是表格数据
## 行与列
大多数工作数据都存放在**表格**中。在组织良好的表格里：
- 每一**行**是一条记录（一笔销售、一位客户、一天）；
- 每一**列**是这条记录的一个属性（日期、金额、城市）；
- 第一行是列**标题**。

这种布局叫“整洁数据”（tidy data）。公式、筛选、数据透视表以及所有分析工具都基于它工作。

## 数据类型
每一列都有类型：
- **数字**——可以计算（求和、计数）；
- **文本**——名称、标签、类别；
- **日期和时间**——在软件内部也是数字，所以可以相减和分组；
- **逻辑值**——TRUE/FALSE。

一个常见错误是把数字存成文本（例如“1,200 元”）。软件无法对它求和。应该把单位写在标题里：“金额（元）”。

# data-02 | 数据如何组织 | 干净的数据
## 典型的混乱
在脏数据上做分析会得出错误结论。最常见的问题：
- **重复**——同一条记录出现两次；
- **多余的空格**和不同写法：“Beijing”“beijing”“Beijing ”；
- **不同的日期格式**：同一列里既有 03/04/2025 又有 2025-04-03；
- **合并单元格**——会破坏排序和筛选；
- **缺失值**和占位符，例如“—”“无”，或用 0 代替“没有数据”；
- **一张工作表里放好几张表**，数据中间夹着合计行。

## 如何清理
- 用内置命令删除重复项（数据 → 删除重复项）。
- **TRIM** 函数去除多余空格；**UPPER/LOWER/PROPER** 统一英文大小写。
- 对类别使用**下拉列表**（数据验证），避免出现新的写法。
- 空值和零不是一回事：0 表示“零”，空单元格表示“未知”。
- 单独保留原始数据，在副本上清理。

# data-03 | 公式 | 公式与引用
## 公式如何工作
公式以 **=** 号开头。例如 `=B2*C2` 把 B2 和 C2 单元格的值相乘。如果原始数字变了，结果会自动重新计算——这就是电子表格的威力。

基础函数：
- **SUM**——求和：`=SUM(D2:D100)`；
- **AVERAGE**——平均值；
- **COUNT**——包含数字的单元格个数；**COUNTA**——非空单元格个数；
- **MIN / MAX**。

中文版 Excel 和 WPS 使用英文函数名。在某些地区设置的 Excel 中，函数名会被翻译，参数用分号而不是逗号分隔：`=IF(A2>0;1;0)`。

## 相对引用和绝对引用
把公式向下复制时，引用会**跟着移动**：`=B2*C2` 到下一行变成 `=B3*C3`。这就是**相对**引用。

如果某个引用必须固定（例如 F1 单元格里的汇率），就用美元符号锁定它：`=B2*$F$1`。这是**绝对**引用。在 Excel 中，按 F4 键可以切换引用类型。

!key 复制公式时，相对引用会移动。
!key $F$1 是绝对引用——不会移动。

# data-04 | 公式 | 条件：IF 与按条件计数
## IF 函数
**IF** 根据条件选择结果：`=IF(条件, 条件为真时的值, 条件为假时的值)`。

例子：`=IF(D2>=100000,"大单","普通")` 把 10 万及以上的订单标为大单。

条件由比较构成：`>`、`<`、`>=`、`<=`、`=`、`<>`（不等于）。多个条件用 **AND** 和 **OR** 组合：`=IF(AND(D2>0,E2="上海"),1,0)`。

## 按条件计数和求和
- **COUNTIF**——满足条件的单元格个数：`=COUNTIF(E2:E100,"上海")`。
- **SUMIF**——按条件求和：`=SUMIF(E2:E100,"上海",D2:D100)`——只算上海的收入。
- 多个条件时，用 **COUNTIFS** 和 **SUMIFS**。

层层嵌套的 IF 很难读懂。如果情况很多，最好单独建一张对照表并在其中查找——这是下一课的内容。

!key IF(条件, 为真时, 为假时) 按条件选择结果。
!key AND / OR 组合多个条件。
!key COUNTIF 和 SUMIF 按条件计数和求和。
!key 大量嵌套 IF 说明你需要一张对照表。

# data-05 | 公式 | 查找数值：VLOOKUP 和 XLOOKUP
## 为什么要查找
数据经常分散在不同的表格里：一张是订单和产品编号，另一张是带价格的对照表。查找函数根据键值把需要的数据取过来。

## VLOOKUP 和 XLOOKUP
**VLOOKUP** 在区域的第一列中查找某个值，并返回同一行指定列中的值：
`=VLOOKUP(A2,价格!A:C,3,FALSE)`

最后一个参数 **FALSE** 表示精确匹配——几乎总是需要它。没有它，VLOOKUP 可能返回“最接近”的值，悄无声息地出错。

VLOOKUP 的局限：只在第一列查找、只能向右取值，而且插入新列后列号就会出错。

新版 Excel 和 Google 表格中的 **XLOOKUP** 更方便：`=XLOOKUP(A2,价格!A:A,价格!C:C)`——分别指定在哪里找、返回什么；默认就是精确匹配。经典的替代方案是 **INDEX + MATCH** 组合。

## 键值必须唯一
如果同一个编号在对照表中出现两次，函数会返回第一个匹配项——而你不会察觉这个错误。要检查键值是否唯一。

!key 查找函数根据键值从另一张表取值。
!key 在 VLOOKUP 中使用 FALSE（精确匹配）。
!key XLOOKUP 更方便：“在哪里找”和“返回什么”分开指定。
!key 对照表中的键值必须唯一。

- 结果将是文本
- 从下往上查找
= 没有精确匹配，VLOOKUP 可能返回错误的值。

?q:m XLOOKUP 比 VLOOKUP 方便在哪里？
+ 分别指定在哪里找、返回什么，而且可以向左查找
- 它只能处理文本

?q:h VLOOKUP 返回了价格，但有些不对。对照表中有些编号有两行，价格不同。这是怎么回事？

# data-06 | 分析 | 排序、筛选和数据透视表
## 排序和筛选
**排序**让行按顺序排列：按收入从高到低、按日期。要选中整张表，否则可能只排了一列，把行与行之间的数据打乱。

**筛选**暂时隐藏不满足条件的行——例如只显示一个地区。数据并没有被删除。

## 数据透视表
**数据透视表**能在一分钟内把成千上万行数据变成一份简短的报表。你把字段拖到四个区域：
- **行**——按什么分组（例如销售人员）；
- **列**——第二个维度（例如月份）；
- **值**——计算什么：求和、计数、平均值；
- **筛选**——限定报表范围（例如只看 2025 年）。

数据透视表只适用于整洁数据：标题在第一行，中间没有合并单元格或空行。源数据变化后，需要**刷新**数据透视表。

!key 对整张表排序，而不是只排一列。
!key 筛选会隐藏行，但不会删除它们。
!key 数据透视表有行、列、值和筛选四个区域。
!key 源数据变化后要刷新数据透视表。

?q:e 筛选有什么作用？

+ 暂时隐藏不满足条件的行
- 按字母顺序排序
- 合并单元格
= 隐藏的行仍然留在表中。

?q:m 为什么只对选中的一列排序很危险？

- 排序不会生效
- 表格会变小
- 只对日期有危险
= 一行必须保持为一条完整的记录。

?q:m 你想看每位销售人员每个月的收入。数据透视表的“值”区域放什么？

- 月份
+ 收入求和

= 值就是要计算的内容。

?q:h 你在源表中添加了新的销售记录，但数据透视表仍显示旧的合计。问题在哪里？
- 数据透视表无法处理新数据
+ 需要刷新数据透视表，而且它的数据范围必须包含新行
- 应该删掉数据透视表，手工做报表
- 新的销售记录录入有误
= 数据透视表不会像公式那样自动重新计算。

?r:m 数据透视表的四个区域是什么？
+ 行、列、值、筛选
- 标题、正文、说明、合计
- 单元格、工作表、工作簿、文件
- 求和、平均值、最小值、最大值
= 字段就分布在这些区域中。

?r:e 数据透视表需要什么样的数据？
- 什么样都行，有合并单元格也可以
+ 整洁的数据：标题在第一行，没有合并单元格
- 只能是文本

# data-07 | 分析 | 平均值、中位数和百分比
## 平均值和中位数
**平均值**是总和除以个数。**中位数**是全部数据排序后位于中间的值。当数据中有**极端值**（特别大或特别小的值）时，平均值会大幅偏移，而中位数不会。

例子：五名员工的收入分别是 5、5.5、6、6.5 和 50 万。平均值是 14.6 万，尽管其中四个人的收入都不超过 6.5 万。中位数是 6 万，更能代表典型员工。电子表格中用 **MEDIAN**。

## 百分比和百分点
- 从 200 增长到 250，是 **+25%**：(250 − 200) / 200。
- 如果转化率从 2% 变成 3%，那是增长了 **1 个百分点**，但相对增长是 **50%**。混淆这两者是报告中的常见错误。
- 基数很小的百分比会误导人：“增长 100%”可能只是从 1 单变成 2 单。

!key 有极端值时，中位数比平均值更稳健。
!key 变化百分比 =（新值 − 旧值）/ 旧值。
!key 百分点是百分比之差，不要和百分比混淆。
!key 看基数：小数字上的大百分比说明不了什么。

?q:e 什么是中位数？
- 所有值的总和
+ 排序后位于中间的值
- 出现次数最多的值
- 最大值与最小值之差
= 一半的值低于中位数，一半高于中位数。

?q:m 工资分别是 4、4.5、5、5.5 和 40 万。哪个指标更能代表典型工资？
- 平均值——11.8 万
+ 中位数——5 万
- 最大值——40 万
- 总和——59 万
= 40 万这个极端值把平均值大大拉高了。

?q:m 收入从 16 万增长到 20 万。增长了百分之几？
- 20%
+ 25%
- 40%
- 80%
= (20 − 16) / 16 = 0.25。

?q:h 退货率从 8% 降到 6%。怎样正确描述这个变化？
- 相对下降了 2%
+ 下降了 2 个百分点，即相对于之前的水平下降了 25%
- 下降了 6%
- 下降了 33 个百分点
= 8 − 6 = 2 个百分点；2 / 8 = 25%。

?r:m 为什么平均值可能会误导人？
+ 极端值会使它大幅偏移
- 它总是低于中位数
- 电子表格算不出来
- 它只适用于日期
= 这种情况下要看中位数。

?r:e 变化百分比怎么算？
- 新值减旧值
+ （新值 − 旧值）/ 旧值
- 新值 / 100
- 旧值 / 新值
= 用变化量除以起始值。

!rubric 给出了句子或例子
!rubric 检查了百分比或百分点
!rubric 评估了基数
!model 一份报告说“线上销售占比增长了 5%”：原来是 20%，现在是 25%。正确的说法是增长了 5 个百分点，即相对之前的占比增长了 25%。基数没问题——每月有几千笔订单——所以这个变化是有意义的。

# data-08 | 分析 | 不撒谎的图表
## 选择图表
- **折线图**——随时间的变化：每月收入。
- **柱形图/条形图**——比较类别：各地区销售额。标签较长时，横向条形图更合适。
- **饼图**——整体中的各部分，而且只适用于部分很少时（最多 4–5 个）。角度很难比较，所以条形图往往更好。
- **散点图**——两个数值指标之间的关系：价格和销量。

## 诚实
- 柱形必须**从零开始**：截断的坐标轴会把 3% 的增长变成“暴涨”。
- 不要在不加说明的情况下比较长度不同的时期。
- 标注坐标轴和单位，注明来源和时间段。
- 一张图——一个信息。用颜色突出重点，其余用灰色。

## 课程总结
整洁的表格 → 干净的数据 → 公式和查找 → 数据透视表 → 正确的百分比 → 诚实的图表。这是任何职业中处理数据的基本循环。

!key 折线看时间，柱形做比较，饼图看少数几部分的占比。
!key 柱形从零开始，否则图表会夸大差异。
!key 标注坐标轴、单位、来源和时间段。
!key 一张图——一个信息，重点用颜色突出。

?q:e 哪种图表最能展示一年中每月的收入？
- 饼图
+ 折线图
- 只有一个数字的表格
- 没有标注的散点图
= 折线很好地展示了随时间的变化。

?q:m 什么时候适合用饼图？
- 比较 15 个地区
+ 展示整体中的各部分，且部分很少时
- 展示每日趋势
- 展示两个指标之间的关系
= 扇区太多就难以比较。

?q:m 坐标轴不从零开始的柱形图有什么危险？
+ 小差异看起来很大
- 图表变得太宽
- 标签会消失
- 没有危险，这是标准做法
= 柱子的高度必须与数值成正比。

?q:h 你想检验某个产品价格越高是否卖得越差。选哪种图表？
- 价格占比的饼图
+ 价格与销量的散点图
- 只有价格的折线图
- 按产品名称字母顺序排列的柱形图
= 散点图展示两个数值指标之间的关系。

?r:m 图表上必须始终标注什么？
+ 坐标轴、单位、来源和时间段
- 只要标题
- 什么都不用，一目了然
- 只要背景色
= 缺少这些，图表很容易被误读。

?r:e 哪条规则有助于让图表清晰？
- 颜色越多越好
+ 一张图——一个信息
- 总是加上 3D 效果
- 所有标签都用小字号
= 突出重点，弱化其余部分。
