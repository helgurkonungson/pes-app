# think-01 | 论证 | 主张、论证与证据
## 论证由什么组成
**主张**是某人认为正确的观点：“远程办公能提高效率。”**论证**是主张加上支持它的理由。**证据**是理由所依据的事实：数据、研究、可核实的观察。

批判性思维从一个简单的问题开始：**“我为什么要相信这个？”**如果一个主张背后没有理由和证据，那它只是观点，不是论证。

## 证据的强度
证据有强有弱。大致从弱到强：
- 某一个人的故事（“我爷爷抽烟也活到了 90 岁”）；
- 没有来源的观点；
- 专家在其专业领域内的意见；
- 系统的数据和研究；
- 许多独立研究得出的一致结果。

一个生动的故事比统计数据更容易记住，但它对整体情况的说明要少得多。

!key 论证 = 主张 + 理由 + 证据。
!key 关键问题：“我为什么要相信这个？”
!key 对于一般性结论，个人故事是最弱的证据。
!key 最有力的是许多独立研究得出的一致数据。

?q:e 什么是论证？
- 大声说出的观点
+ 主张加上支持它的理由和证据
- 任何争吵
- 没有答案的问题
= 没有理由，主张就只是观点。

?q:m 对于“吸烟无害”这一结论，哪项证据最弱？
+ 一个吸烟者活到 90 岁的故事
- 对数十万人的研究
- 对许多独立研究的综述
- 全国医疗统计数据
= 一个案例无法说明平均风险。

?q:m 批判性思维从哪个问题开始？
- “谁的声音最大？”
- “现在流行什么？”
+ “我为什么要相信这个？”
- “我怎样才能证明自己是对的？”
= 这个问题要求给出理由和证据。

?q:h 一位同事说：“新的 CRM 系统拖慢了我们——昨天艾琳半小时都打不开一张客户卡片。”你怎样评价这个论证？
- 这是有力的证据，因为例子很具体
+ 这只是一个案例；需要比较许多员工在切换前后的工作速度数据
- 论证是错的，因为艾琳搞错了
- 论证是对的，因为大家都在议论
= 具体的例子是需要核查的理由，而不是结论。

?r:m 观点和论证有什么区别？
+ 论证有理由和证据，观点没有
- 没有区别
- 观点总是错的
- 论证总是更长
= 有依据，主张才成为论证。

?r:e 为什么生动的故事比统计数据更有说服力？
- 因为它更准确
+ 因为它更容易记住，尽管对整体情况说明得更少
- 因为统计数据总是骗人
- 因为科学家会核查故事
= 有感染力不等于证据有力。

!rubric 给出了主张

# think-02 | 论证 | 逻辑谬误（一）
## 推理中的错误
**逻辑谬误**是一种看起来像论证、实际上并不能支持结论的手法。了解它们，能帮你在别人——以及自己——身上发现它们。

## 三种常见谬误
- **人身攻击**：攻击人而不是论点。“他懂什么经济，他连车都不会开。”
- **稻草人**：把对方的立场歪曲成容易攻击的样子。——“我们削减一下广告预算吧。”——“所以你是想让以后再也没人知道我们？”
- **虚假两难**：明明有更多选择，却只给出两个。“你要么站在我们这边，要么就是反对我们”；“要么裁掉半个部门，要么公司倒闭。”

如何应对：把讨论拉回正题（“我们来讨论论点本身”），澄清自己的立场（“我建议的是削减，不是取消”），并询问还有哪些其他选择。

!key 谬误看似论证，却不能支持结论。
!key 人身攻击针对的是人，而不是他的论点。
!key 稻草人反驳的是被歪曲的立场。
!key 虚假两难隐藏了其他选择。

?q:e 这是哪种谬误：“别听她对税收的看法——她只是个学生”？
+ 人身攻击
- 虚假两难
- 稻草人
- 这是有效的论证
= 评判的是人，而不是她的论点。

?q:m ——“我们应该多在家办公。”——“所以你的意思是永远不来办公室、不和团队交流？”这是哪种谬误？
- 人身攻击
+ 稻草人
- 诉诸多数
- 错误归因
= 立场被歪曲到极端，以便更容易攻击。

?q:m “要么这个月发布产品，要么我们永远失去市场。”这句话有什么问题？
- 没问题，说得对
- 这是人身攻击
+ 这是虚假两难：还有其他选择——部分发布、试点、推迟一个月
- 这是可靠的统计
= 选择被人为地缩小到两个极端。

?q:h 在工作讨论中遇到稻草人谬误，最好怎样回应？
- 生气并结束对话
- 用人身攻击回击
+ 冷静地澄清自己真正的立场，回到正题
- 同意被歪曲的说法
= 澄清能把讨论带回真正的提议。

?r:m 什么是虚假两难？
+ 把情况描述得好像只有两种选择
- 计算错误
- 对人的攻击
- 诉诸权威
= 现实中通常有更多选择。

?r:e 人身攻击针对的是什么？
- 论点
+ 人，而不是他的论点
- 统计数据
- 信息来源
= 它的拉丁文名称 ad hominem 意为“针对人”。

# think-03 | 论证 | 逻辑谬误（二）
## 另外四个陷阱
- **诉诸多数**：“大家都这么做，所以是对的。”受欢迎不等于正确。
- **诉诸权威**（领域之外）：著名演员为药品做广告。专家的意见**在其专业领域内**、并且有数据支撑时才有分量。
- **滑坡谬误**：“如果允许迟到 5 分钟，很快大家就会到中午才来。”没有证据就宣称一连串后果必然发生。
- **后此谬误**（“在此之后，因此由此造成”）：“我穿了幸运毛衣，球队就赢了。”一件事发生在另一件事之后，并不意味着是它造成的。

## 如何核查
问一问：有没有数据，而不只是受欢迎？专家是否在谈自己的领域？链条中每一环的可能性有多大？还有哪些原因可能导致这个结果？

!key 一个观点受欢迎并不能证明它正确。
!key 权威的意见只有在其领域内且有数据支撑时才算数。
!key 滑坡谬误在没有证据的情况下宣称连锁后果必然发生。
!key “之后”不等于“因为”。

?q:e “数百万人都在喝这种减肥茶，所以它有效。”这是哪种谬误？
+ 诉诸多数
- 滑坡谬误
- 稻草人
- 虚假两难
= 受欢迎不能证明有效。

?q:m “换了标志以后销量上升了，所以是新标志起了作用。”问题在哪里？
- 没问题，这就是证据
+ 这是后此谬误：季节、价格或广告都可能影响销量
- 这是人身攻击
- 这是诉诸权威
= 需要排除其他原因。

?q:m 专家的意见什么时候是有力的论据？
- 总是，只要专家有名
+ 当他在自己的领域内发言并依据数据时
- 当他有很多粉丝时
- 当他听起来很自信时
= 领域之外的权威不构成论据。

?q:h “如果允许员工每周在家办公一天，很快就没人干活了。”怎样回应更有建设性？
- 同意：肯定会这样
+ 询问链条中每一环的依据，并建议先试点、衡量结果
- 指责对方懒惰
- 说所有公司都这么做
= 滑坡谬误要通过每一步的证据来检验。

?r:m 什么是滑坡谬误？
+ 没有证据就声称迈出一步必然导致一连串坏结果
- 冬天危险的路
- 诉诸多数
- 计算错误
= 每一环都需要单独证明。

?r:e 为什么一个观点受欢迎并不能证明它正确？
- 受欢迎的观点总是错的
+ 很多人可能同时犯错
- 因为受欢迎程度无法衡量
- 它能证明
= 真相由数据决定，而不是由支持者人数决定。

# think-04 | 思维陷阱 | 认知偏差
## 快速却歪斜的规则
大脑通过快速的经验法则——**启发式**——来节省力气。它们通常有用，但在可预测的情况下会系统性地出错。这些错误叫作**认知偏差**，心理学家丹尼尔·卡尼曼和阿莫斯·特沃斯基对它们做了详细描述。

## 三种重要的偏差
- **确认偏差**：我们注意并寻找支持自己观点的信息，忽略与之矛盾的信息。
- **锚定效应**：最先听到的数字会影响我们的估计。如果卖家先报一个高价，“折扣”就显得很大方。
- **可得性启发**：我们根据例子有多容易想起来判断事件的可能性。看到空难新闻后，坐飞机似乎更危险了，但从统计上看，飞机是最安全的出行方式之一。

## 有什么帮助
- 刻意寻找**反对**自己立场的论据。
- 在听到别人的数字之前，先做出自己的估计。
- 问自己：“根据数据，这种事实际上多常发生？”

!key 认知偏差是快速思维规则的系统性错误。
!key 确认偏差：我们看到支持自己观点的东西。
!key 锚定：第一个数字会左右估计。
!key 可得性：生动的例子显得常见——查一查数据。

?q:e 什么是确认偏差？
+ 倾向于注意支持自己观点的信息，忽略与之矛盾的信息
- 总是附和老板的习惯
- 确认付款时的错误
- 事实核查
= 我们为已经相信的东西寻找“证据”。

?q:m 卖家先报价 1,200，然后给出“折扣价” 800。利用的是哪种偏差？
- 可得性
+ 锚定
- 稻草人
- 虚假两难
= 第一个数字让第二个价格显得很有吸引力。

?q:m 为什么看到空难新闻后，很多人觉得坐飞机比开车更危险？
- 因为统计数据就是这么说的
+ 生动的例子很容易想起来，我们会高估它们发生的频率
- 因为锚定在机票价格上
- 因为虚假两难
= 这就是可得性启发。

?q:h 你确信新供应商比老供应商好。哪一步最能防范确认偏差？
- 找三条支持你观点的评价
- 只问意见一致的人
+ 刻意寻找不利于新供应商的论据和数据
- 尽快做决定
= 寻找反面证据可以平衡天然的倾向。

?r:m 谈判中怎样防范锚定效应？
+ 在任何人报出数字之前，先做出自己的估计
- 总是接受第一个报价
- 从不说任何数字
- 参照竞争对手的价格
= 自己的估计能削弱锚的拉力。

?r:e 谁详细描述了许多认知偏差？
- 阿尔伯特·爱因斯坦
+ 丹尼尔·卡尼曼和阿莫斯·特沃斯基
- 艾萨克·牛顿
- 西格蒙德·弗洛伊德
= 他们的研究奠定了行为经济学的基础。

# think-05 | 思维陷阱 | 相关与因果
## 一起变化不等于因果
**相关**是指两个指标一起变化。**因果**是指一个导致另一个。经典例子：冰淇淋销量和溺水人数一起上升。冰淇淋不会让人溺水——两者都因夏天炎热而上升。这是**隐藏的第三个原因**。

相关还可能有其他解释：
- **反向因果**：不是“运动让人健康”，而是健康的人运动得更多（实际上两个方向都在起作用）；
- **巧合**：数据多了，偶然的吻合是不可避免的。

## 抽样错误
- **选择偏差**：在网上调查人们是否使用互联网。
- **幸存者偏差**：只研究成功者。第二次世界大战期间，统计学家亚伯拉罕·瓦尔德建议，不要加固返航飞机上弹孔多的部位，而要加固没有弹孔的部位——那些部位中弹的飞机没能飞回来。

检验因果关系的最好方法是**随机分组实验**：这样第三个原因会被均匀地分配到各组。

!key 相关：指标一起变化；因果：一个导致另一个。
!key 寻找隐藏的第三个原因、反向因果和巧合。
!key 幸存者偏差：只研究成功者会得出错误结论。
!key 随机实验是检验因果的最佳方法。

?q:e 冰淇淋销量和溺水人数一起上升。为什么？
- 冰淇淋导致溺水
+ 两者都因夏天炎热而上升——隐藏的第三个原因
- 溺水增加了冰淇淋销量
- 这是已被证实的因果关系
= 相关不等于因果。

?q:m 什么是幸存者偏差？
+ 只根据“幸存”的案例下结论，看不到被淘汰的那些
- 医学统计中的错误
- 平均值算错了
- 害怕风险
= 例如只研究成功的创业公司。

?q:m 一个旅游网站上的调查显示，90% 的人每年都出国旅行。问题在哪里？
- 没有问题
- 这个百分比太小
+ 样本有偏差：访问该网站的主要是旅行者
- 调查应该在夜里做
= 样本不能代表所有人。

?q:h 一家公司发现，参加过销售培训的员工卖得更多。什么最能可靠地证明培训就是原因？
- 询问培训参与者的看法
+ 把条件相似的员工随机分为参加和不参加培训两组，比较结果
- 计算培训花了多少钱
- 只派最优秀的销售人员去培训
= 随机分组排除了隐藏原因——例如最有干劲的人更愿意报名。

?r:m 关于飞机装甲，亚伯拉罕·瓦尔德提出了什么建议？
+ 加固返航飞机上没有弹孔的部位
- 加固返航飞机上有弹孔的部位
- 完全不加固飞机
- 把飞机漆成别的颜色
= 那些部位中弹的飞机正是没能返航的。

?r:e 相关和因果有什么区别？
- 没有区别
+ 相关是一起变化，因果是一个因素导致另一个
- 因果是一种弱相关
- 相关只存在于经济学中
= 一起变化并不能说明谁导致谁。

# think-06 | 信息 | 如何核查信息来源
## 关于来源的五个问题
1. **作者是谁？**懂这个领域吗？有利益冲突吗？
2. **数据从哪里来？**有没有指向一手来源——研究、文件、统计数据——的链接？
3. **什么时候发布的？**信息是否过时？
4. **为什么写？**为了告知、推销、说服，还是激起愤怒？
5. **有其他独立来源证实吗？**

## 横向阅读
专业的事实核查员不会深入研究一个可疑的网站，而是立刻**打开新标签页**，看看别人怎么评价这个网站和作者。这叫**横向阅读**。斯坦福历史教育小组（Stanford History Education Group）的研究表明，事实核查员用这种方法识别不可靠来源，比历史学家和学生更快、更准确。

## 危险信号
情绪化的标题、“医生不想让你知道”、没有作者或日期、链接兜兜转转又回到同一个网站、没有出处的照片。照片可以用**以图搜图**（反向图片搜索）来核查——常常会发现它是旧照片，或来自另一个国家。

!key 五个问题：谁写的、从哪来、什么时候、为什么、还有谁证实。
!key 横向阅读：看看别人怎么评价这个来源。
!key 危险信号：情绪化、“他们在隐瞒”、没有作者或日期。
!key 用以图搜图核查照片。

?q:e 关于来源的哪个问题有助于揭示利益冲突？
- 网站用的是什么字体？
+ 作者是谁？如果你相信了，他能获益吗？
- 文章有多少点赞？
- 网站上有广告吗？
= 作者可能希望得出某个特定结论。

?q:m 什么是横向阅读？

+ 在新标签页中查看其他网站对这个来源的评价，以此核查它
- 只看标题
- 同时读两篇文章
= 专业事实核查员就是这样工作的。

?q:m 你在社交媒体上看到一张“现场”拍的震撼照片。怎样最快地核查它是不是旧照片？

# think-07 | 信息 | 会误导人的数字
## 相对风险与绝对风险
“风险降低一半”听起来很厉害。但如果风险原来是万分之二，现在变成万分之一，绝对降幅只是每一万人中少一例。永远要问：**“原来是多少，现在是多少，用绝对数字表示？”**

## 基础比率
一种罕见病的检测准确率为 99%。这种病每 1,000 人中有 1 人患病。在 1,000 名受检者中，那位患者几乎肯定会检测为阳性——但大约还有 10 名健康人也会得到假阳性。所以检测呈阳性时，真正患病的概率大约是 1/11，而不是 99%。忽视基础比率是最常见的错误之一。

## 其他陷阱
- **样本太小**：“5 位牙医中有 4 位推荐”——是哪 5 位？
- **挑选时间段**：从“最低点”开始画的图，显示出的增长在更长的时间段里并不存在。
- 有极端值时**用平均值代替中位数**。
- **没有比较的数字**：“1,000 起事故”——对这样规模的城市来说是多还是少？

!key 问绝对数字：“原来是多少，现在是多少”。
!key 注意基础比率：罕见事件会产生大量误报。
!key 小样本和挑选的时间段会扭曲事实。
!key 没有比较的数字毫无意义。

?q:e 广告说：“这种药能让风险降低一半。”首先应该问什么？
- 这种药多少钱？
+ 用药和不用药的风险分别是多少，用绝对数字表示？
- 包装是谁生产的？
- 有多少人买了这种药？
= “降低一半”可能只是从万分之二降到万分之一。

?q:m 风险从每万人 4 例降到每万人 2 例。绝对降幅是多少？
- 每百人 50 例
+ 每万人 2 例
- 50%
- 每万人 4 例
= 相对来说是减半；绝对来说是每万人 2 例。

?q:m “受访的 5 位牙医中有 4 位推荐这款牙膏。”首先让人怀疑的是什么？
+ 一共调查了多少位牙医，以及他们是怎么选出来的
- 包装的颜色
- 牙膏的价格
- 品牌名称
= 样本太小或经过挑选，可以得出任何结果。

?q:h 一种疾病每 1,000 人中有 1 人患病。检测在健康人中约有 1% 的假阳性。你的结果是阳性。哪种说法更接近事实？
- 你几乎肯定患病了（99%）
+ 患病概率不高——大约 1/11；需要复查或换一种检测
- 概率正好是 50%
- 这个检测毫无用处
= 每一个真病例对应大约 10 个假阳性——这就是基础比率。

?r:m 为什么不能脱离背景比较数字？
+ 没有比较的基准，就无法判断是多还是少
- 数字总是骗人
- 背景只对科学家有用
- 比较会让人糊涂
= 例如，事故数量必须与城市规模联系起来看。

?r:e 什么是绝对风险？
- 相对于去年的百分比风险
+ 实际发生该事件的人所占的比例
- 可能的最大风险
- 广告里提到的风险
= 例如万分之二。

# think-08 | 信息 | 如何争论与改变看法
## 为理解而争论
好的争论目的不是赢，而是**更接近真相**。有用的技巧：
- **钢铁人**（steelman）——与稻草人相反：用对方最有力的形式复述他的立场，让他本人也认同你的复述。然后再回应。
- **用提问代替攻击**：“什么能改变你的看法？”“你依据的是什么数据？”
- 把**事实**（“销售额下降了 10%”）和**价值观**（“留住员工比利润更重要”）分开——争论它们的方式不同。

## 用百分比表达把握
信念不必只分成“相信 / 不相信”。用概率来思考会有帮助：“我有 70% 的把握。”新的数据会一点点改变你的把握程度。承认“我错了”是思维强大的表现，而不是软弱。

## 课程总结
追问理由和证据，留意谬误和偏差，核查来源和数字，诚实地争论。批判性思维是一种技能，和其他技能一样需要训练：定期练习，用真实的例子练习。

!key 好的争论是为了更接近真相，而不是为了赢。
!key 钢铁人：用最有力的形式复述对方的立场。
!key 把关于事实的争论和关于价值观的争论分开。
!key 用概率思考，根据数据改变看法。

- 永远不改变看法

- 两句都是价值观
