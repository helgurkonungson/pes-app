Exemple de leçon: Qu’est-ce qu’un tableau de données

Lignes et colonnes

La plupart des données professionnelles se trouvent dans des tableaux. Dans un tableau bien organisé :

  • chaque ligne est un enregistrement (une vente, un client, un jour) ;
  • chaque colonne est un attribut de cet enregistrement (date, montant, ville) ;
  • la première ligne contient les en-têtes de colonnes.

Cette organisation s’appelle des « données bien rangées » (tidy data). Les formules, les filtres, les tableaux croisés dynamiques et tous les outils d’analyse fonctionnent avec elle.

Types de données

Chaque colonne a un type :

  • nombres : on peut calculer avec (somme, nombre) ;
  • texte : noms, libellés, catégories ;
  • dates et heures : dans le logiciel, ce sont aussi des nombres, on peut donc les soustraire et les regrouper ;
  • valeurs logiques : VRAI/FAUX.

Une erreur fréquente est un nombre enregistré comme texte (par exemple « 1 200 € »). Le logiciel ne peut pas l’additionner. Mettez plutôt l’unité dans l’en-tête : « Montant, € ».

L’essentiel
  • Une ligne est un enregistrement, une colonne un attribut, la première ligne contient les en-têtes.
  • Un tableau bien rangé fonctionne avec les formules, les filtres et les tableaux croisés dynamiques.
  • Les types principaux : nombres, texte, dates, valeurs logiques.
  • Ne mélangez pas nombres et texte dans une cellule : l’unité va dans l’en-tête.
Question ouverte en fin de leçon

Prenez un tableau de votre travail ou de votre vie (un budget, des ventes, une liste de tâches). Décrivez ses lignes, ses colonnes et ses types de données, et ce qu’on pourrait améliorer.

Réponse modèle

Mon tableau de dépenses : une ligne est un achat, les colonnes sont la date (date), la catégorie (texte), le montant (nombre), carte ou espèces (texte). Amélioration : les montants sont écrits « 35 € » ; je vais retirer le « € » et mettre l’unité dans l’en-tête « Montant, € » pour pouvoir les additionner.
