Sample lesson: What tabular data is

Rows and columns

Most work data lives in tables. In a well-organised table:

  • each row is one record (one sale, one customer, one day);
  • each column is one attribute of that record (date, amount, city);
  • the first row holds the column headers.

This layout is called "tidy data". Formulas, filters, pivot tables and every analysis tool work with it.

Data types

Every column has a type:

  • numbers — you can calculate with them (sum, count);
  • text — names, labels, categories;
  • dates and times — inside the program these are numbers too, so you can subtract and group them;
  • logical values — TRUE/FALSE.

A common mistake is a number stored as text (for example, "1,200 USD"). The program can't add it up. Put units in the header instead: "Amount, USD".

Key points
  • A row is one record, a column is one attribute, the first row holds headers.
  • A tidy table works with formulas, filters and pivot tables.
  • The main types: numbers, text, dates, logical values.
  • Don't mix numbers and text in a cell: units go in the header.
Open question at the end of the lesson

Take a table from your work or life (a budget, sales, a to-do list). Describe its rows, columns and data types, and what could be improved.

Model answer

My expenses table: a row is one purchase, the columns are date (date), category (text), amount (number), card or cash (text). Improvement: amounts are currently written as "35$", so I'll remove the "$" and put the units in the header "Amount, USD" so they can be added up.
